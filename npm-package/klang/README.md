# klang

Klang language CLI (npm wrapper).

Install globally:

```sh
npm install -g klang
klang --version
```

The wrapper resolves to the prebuilt platform binary shipped in the
matching optional package (`klang-linux-x64`, `klang-linux-arm64`,
`klang-darwin-x64`, `klang-darwin-arm64`, `klang-win32-x64`).
