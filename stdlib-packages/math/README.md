# math

Math constants and integer/float helpers.

## API

- `math_pi() -> f64`, `math_e() -> f64`
- `math_abs(n)`, `math_max(a, b)`, `math_min(a, b)`, `math_clamp(v, lo, hi)`
- `math_pow(base, exp) -> i32`, `math_fact(n) -> i32`
- `math_circle_area(r: f64) -> f64`
