## Decisions taken without asking (rule 13)

1. **No native duplicates of package APIs.** `json_parse`, `csv_parse`,
   `base64_encode`, `hex_encode`, `path_join`, `str_repeat`,
   `text_pad_left`, `rand_new`, … already exist as tested pure-Klang
   packages. A same-named native builtin would trip `W-SHADOW` and break the
   package plus its parity self-test. B1 adds natives only under names no
   package uses (audit table in `B1-audit.md`).
2. **`sprintf(fmt, args_array)`** (not variadic, not `format` changed):
   `format(...)` keeps its join-with-spaces contract; the new builtin takes
   exactly `(fmt: str, args: array)`.
3. **String pads/repeat/lines are methods** (`"s".pad_start(w, pad)`), so
   they cannot collide with package flat functions. They are width-exact
   and loud where the packages are overshooting/silent (documented below).
4. **No bytes type.** Binary safety stays base64/hex packages + lossy-UTF-8
   transport, as §5 allows.
5. **`len()` stays bytes.** Changing it to chars would break existing gates;
   the bytes-vs-chars split is documented, not fixed, in B1.

## Builtin signatures

| Builtin | Signature | Returns |
|---|---|---|
| `regex_find_all` | `(pat: str, text: str)` | `array<str>` all non-overlapping matches in order (`[]` on no match) |
| `regex_replace` | `(pat: str, text: str, repl: str)` | `str`, `$1`/`$name`/`$$` expansion per the `regex` crate |
| `uuid_v4` | `()` | `str` `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx` (`y` ∈ `8/9/a/b`) |
| `path_absolute` | `(path: str)` | `str`, CWD-joined + lexically normalized, no FS touch (infallible) |
| `file_mtime` | `(path: str)` | `f64` secs since epoch (same clock as `time_now()`), guarded by `reject_unsafe_path` |
| `sprintf` | `(fmt: str, args: array)` | `str`; `{}` in order (rendered like `str()`), `{{`/`}}` escapes, extra args ignored |
| `random_seed` | `(seed: i32)` | `i32` 1; reseeds the deterministic RNG |
| `random_seeded_int` | `(lo: i32, hi: i32)` | `i32` uniform inclusive, rejection-sampled |
| `random_seeded_float` | `()` | `f64` uniform `[0.0, 1.0)` |
| `"s".pad_start` | `(width: i32, pad: str)` | `str`, left-padded to exactly `width` chars (pad cycled) |
| `"s".pad_end` | `(width: i32, pad: str)` | `str`, right-padded, same rules |
| `"s".repeat` | `(n: i32)` | `str`, `s` × `n` (`n == 0` → `""`) |
| `"s".lines` | `()` | `array<str>`, `\n` split, one trailing `\r` stripped per line |

## Limits (all documented in `b1.rs` item docs)

- `MAX_FIND_ALL = 10,000` matches; `MAX_REPLACE_BYTES = 1,000,000`;
  `MAX_STR_CHARS = 1,000,000` (pads/repeat); templates redacted past 200
  chars in diagnostics. `sprintf` has no output cap (same unboundedness as
  `format`/string `+`). Seeded draws cap at 1024 rejection rounds with a
  bounded fallback (mirrors `random_int_inclusive`).
